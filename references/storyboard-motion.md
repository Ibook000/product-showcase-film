# 运镜、装配与衔接

## 从观众要理解的变化选择画面

先写“观众这一段要看懂什么”，再决定镜头。外观用整体构图、尺度与材质；操作用触发点特写和明确结果；装配用能分辨零件关系的角度。不要把同一固定画面换标题后重复多段。

镜头表至少记录：起止拍/秒、主体或零件、景别、相机起终点、动作、结果、共同元素、音乐重音、素材来源。短片通常需要整体、局部、结果与回到整体的变化；段数和停留取决于内容，不设固定镜头数量。

实物、软件、奢侈品或工业设备可以有完全不同的速度与色调。让高能片的动作压在鼓点，阅读和复杂操作仍需足够时间。用户说慢时先压缩等待与重复，再改变镜头；全局加速会缩短本来就难读的画面。

## 真实三维与二维运动

- 透视相机位置变化能产生透视关系和视差；相机焦距变化则改变视野。不要混称。
- 正交场景中的轨道与正交画幅变化可以组成连续三维取景，但没有透视推轨的效果。
- 图片缩放、裁切与平移是二维运动，适合已有照片，不是新建了三维场景。

使用原始模型时先检查单位、坐标、轴向、可见性、对象层级和原有动画姿态。将产品范围用于归一化相机，不要把毫米模型套进米制位置，也不要把展台或地面纳入产品包围盒。

没有 CAD 时，可在用户授权范围内依据尺寸、多视图或产品照片补建展示几何，说明其为展示模型、哪些比例未实测；不能据单张外观照虚构内部结构、精确制造尺寸或隐藏功能。照片自身也可成为最终实物证据：以共同轮廓、相近视角与运动方向连接模型、制作中状态和成品，避免用生成变形改掉真实零件或标志。

维护明确的可动画产品对象集合。恢复零件姿态时不得重置相机和灯光。被选父级与子级不能同时施加同一世界位移，否则会双重运动。透明模型、玻璃、软体、布料、液体、绑定角色或复杂机构应使用任务适配器；通用刚体脚本不能代替这些工作。

## 拆装与更换

按物理作用映射角色，而不是根据未知对象名称猜分类。示例：主体、外盖、可换模块、连接件。分别设计离位方向、距离、先后、停留与复装曲线。

热插拔示例必须区分键帽与轴体；换电池示例必须区分外盖与电池。把外盖抬起不等于证明模块可更换。动画前确认实际功能与机械关系，不用渲染结果反推产品性质。

## 衔接策略

| 策略 | 合适用法 | 检查重点 |
|---|---|---|
| 同一场景连续运镜 | 整体 → 操作点 → 整体 | 相机和目标曲线连续，速度变化有意图，零件不穿模 |
| 共同元素延续 | 输入文本保留并进入编辑；按钮反馈变为进度 | 元素位置、内容、尺寸与状态能对应 |
| 形状匹配 | 旋钮圆环 → 调节反馈；显示条 → 进度条 | 形状、中心、运动方向和接点匹配 |
| 遮挡衔接 | 镜头经过产品边缘或前景，遮挡中连接两段 | 遮挡确实覆盖接缝，前后速度及方向一致 |
| 同向运动 | 转动、滑动或掠过镜头连接另一画面 | 不能突然反向；模糊量与速度相符 |
| 短叠化 | 相近构图的小幅状态变化 | 不产生重影、双重文字或零件漂浮；不称其自动保证无缝 |

把三维控制点投影到实际相机画幅，供二维圆环、指示线、声波等连接。优先使用 Blender 的 `world_to_camera_view`；特定正交场景的手写投影公式不能直接用于任意透视场景。

先验证最难的衔接段，而不是整片渲染后才查看。既检查单帧，也回放前后数秒；单帧正确不能说明运动连续。

## 可选生成式视频

确认当前工具支持视频生成及实际需要的约束，不把剪辑、图片生成或视频摘要接口当作视频生成接口。能控制首尾帧时先用确定性的产品关键帧，再生成短衔接；逐段检查形状、零件数量、标志、颜色、方向和时间连续性。

生成文字、界面数字和精确操作状态容易不稳定，优先后期合成。不能维持一致性时回到原生模型、真实素材或可控动效。记录真正使用的服务、输入、输出及限制，不写未经执行的能力或效果；远端操作遵循当前任务授权。
