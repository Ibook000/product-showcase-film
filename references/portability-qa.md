# 可移植性、节奏与验证

## 其他模型与环境

技能包只需要标准文件读取与命令执行能力。读取 SKILL.md，按目标任务读取 references，调用 scripts；无需 Codex、特定 MCP、Adobe 账户或旧技能。agents/openai.yaml 是可选客户端元数据。

用参数列表启动子进程，避免在 shell 字符串中插入路径、中文、$ 或反引号。Windows 专用创建标志只在 Windows 使用；后台窗口是否隐藏遵循宿主环境规则。工具与字体路径从项目配置、环境变量或系统发现，不能带开发者机器盘符。图片检查遵循宿主环境提供的识图方式，不将某个全局识图脚本或密钥路径当作通用依赖。

分享时只打包技能说明、脚本和无私有资产的配置。工作日志、真实模型、录屏、账号、权重与输出视频留在任务目录。不同模型安装位置由其宿主决定，文件夹本身可直接复制；不自动改其全局配置。

## 容易导致“能跑但画面错”的问题

- **相机被恢复原位**：先移动相机，再对全部对象恢复初始姿态，会撤销相机变化。显式恢复零件白名单，或先恢复零件、最后应用相机。
- **错把地面算产品**：包围盒巨大，产品消失。先 inspect，再设置 include/exclude。
- **层级双重位移**：父子同时移动导致动作翻倍；不重叠选择。
- **旧缓存误用**：只判断文件存在会保留旧镜头。使用签名；外链纹理也纳入依赖。
- **依赖旧工程**：动态导入旧视频脚本、替换源码字符串扩大时长并不是真正参数化。音轨函数要独立接收时长、BPM、采样率和事件。
- **错误投影**：仅适用于某个正交机位的公式套到透视相机，会让指示圈漂移。用实际相机输出投影。
- **时长漂移**：非整数帧拍长取整后反复累加，会逐渐错拍。从绝对拍时间分别量化。
- **母带没削波、MP4 却超峰值**：AAC 编码后复测 true peak，不只看原始 WAV，也不把 loudnorm 参数当成最终峰值证据。
- **录屏混进别的窗口**：审查实际使用的整段，必要时逐帧匹配干净参考；不能只看开头和结尾。

## 核验范围

自动验证：格式、时长、帧数、完整解码、AAC 后峰值、拍点量化误差。确认音频流存在或不存在符合用户要求；无旁白时不可混入说话声或旧录屏音频。

视觉核验：抽查第一帧、所有状态与过渡前后，特别是靠近边缘的零件、中文、品牌、手指动作、反射、重复内容与光标。按宿主可用方式查看关键帧，并回放最难的连续段。检查相机日志和零件状态，但不要把 continuous_camera=true 之类自填标签写成验证结论。

相邻帧亮度/场景差分可定位候选异常，不等于硬切检测或审美判定。快速装配也会产生很大差分，低差分也可能是长时间无变化。需要结合画面与任务意图判断。

输出 1920×1080 不代表源渲染也是 1920×1080。分别记录源尺寸、放大、FPS 和编码；功能示意也不能作为新实测依据。

## 最小验证方式

1. 在任务外的临时工作目录初始化 --demo，检查和渲染短片。
2. 用 assets/functional-project.json 跑不依赖 Blender 的独立动效。
3. 改为非整数帧拍长（例如 24 FPS / 128 BPM），核对 plan 没有累加漂移。
4. 若修改音轨、字幕或代码，复验真正改变的环节；不要无依据反复重渲染整个项目。

实际项目若需 AI 生成、复杂动画或外部服务，再验证相应适配器；内置几何示例通过不能证明这些额外能力已实现。
